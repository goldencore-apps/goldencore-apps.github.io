Quilla

原稿を書く・読む・聴く。Mac / iPhone / iPad

原稿は、ただの .md ファイル

Quilla で書いた原稿は、独自形式ではなく Markdown ファイルとして iCloud Drive に保存されます。 Quilla を使わなくなっても、原稿はほかのテキストエディタでそのまま開けます。

できること

  • Markdown の見出し・太字・表・画像・動画を、書きながらその場で表示
  • ライブラリ → ブック → セクションで原稿を整理。ドラッグで並べ替え
  • iCloud で Mac / iPhone / iPad の原稿を同期
  • 全文検索・版履歴（以前の版に戻せる）・アプリ内のゴミ箱
  • 書き出し: Markdown / MDX / テキスト / HTML / EPUB / Word / PDF（縦書き・ルビ対応）
  • EPUB や HTML の本を読み、蛍光ペンで線を引く
  • 原稿の読み上げ（端末内の音声で再生）

購読について

書く機能は購読でご利用いただけます。購読が終わっても、原稿を読む・書き出すことはいつでもできます。
