Quilla サポート

不具合のご報告・ご質問・ご要望はこちらから。

お問い合わせ

GitHub の Issues で受け付けています（GitHub アカウントが必要です）。

新しい問い合わせを書く ・ これまでの問い合わせを見る

書き込みは誰でも見られます。原稿の本文、APIキー、メールアドレスなどの個人情報は書かないでください。

不具合をご報告いただく時に書いてほしいこと

  • 使っている端末（Mac / iPhone / iPad）と OS のバージョン
  • Quilla のバージョンとビルド番号（設定 → アプリ情報）
  • 何をした時に、何が起きたか。毎回起きるか

よくある質問

購読をやめたら、原稿はどうなりますか？

原稿はそのまま残ります。購読が終わっても、読む・書き出すことはいつでもできます。 原稿は iCloud Drive 上の普通の Markdown ファイルなので、ほかのアプリでも開けます。

購読の解約・購入の復元

解約は Apple の「サブスクリプション」設定から行います（iPhone / iPad: 設定 → 自分の名前 → サブスクリプション）。 機種変更などで購読が反映されない時は、Quilla の購読画面の「購入を復元」を押してください。

端末の間で原稿が同期されません

各端末で同じ Apple Account にサインインし、iCloud Drive がオンになっているか確認してください。
