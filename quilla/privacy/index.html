Quilla プライバシーポリシー

制定日: 2026年10月5日

Quilla（以下「本アプリ」）は、Taizo Yamaoka（以下「開発者」）が提供する Mac / iPhone / iPad 用のアプリです。 このポリシーは、本アプリが利用者の情報をどう扱うかを説明します。

1. 開発者は利用者の情報を集めません

本アプリには、利用状況の解析、広告、トラッキングの仕組みは入っていません。 原稿・設定・利用状況などの情報が、開発者に送られることはありません。開発者が運営するサーバーもありません。

2. 原稿の保存先

原稿・画像などのファイルは、利用者の端末と、利用者自身の iCloud Drive に保存されます。 iCloud での保存と同期は Apple が提供するもので、Apple のプライバシーポリシーに従って扱われます。 利用者が自分で選んだフォルダ（外部フォルダ）を登録した場合は、そのフォルダ内のファイルを読み書きします。

3. 購読（App 内課金）

購読の購入・更新・復元は Apple の App Store を通じて行われます。 支払い情報を本アプリや開発者が受け取ることはありません。

4. マイクと音声認識

音声入力を使う時だけ、マイクと音声認識の許可をお願いします。 音声は Apple の音声認識で文字にします。端末内で認識できる場合は端末内だけで処理します。 端末内で認識できない場合は、Apple のサーバーに送って認識されることがあります。

5. Preview 機能（外部 AI サービス）を使う場合

設定の「Preview 機能を試す」をオンにして、利用者が自分の API キーを登録した場合に限り、 本アプリは利用者が選んだ外部サービスに、端末から直接データを送ります。オフのまま（初期状態）では送りません。

機能送るもの送り先（利用者が選んだもの）
AI 音声での読み上げ読み上げる部分の本文ElevenLabs / OpenAI / Microsoft Azure / Google Cloud / Fish Audio
読み方 AI読み上げる部分の本文OpenAI
挿絵の生成選んだ範囲の本文OpenAI / Google（Gemini）

送ったデータは、各サービスと利用者との契約・プライバシーポリシーに従って扱われます。 サービスや契約によっては、送った内容が AI の学習に使われることがあります。各サービスの規約をご確認ください。 データは開発者を経由せず、開発者が受け取ることもありません。

API キーは端末のキーチェーンにだけ保存され、開発者に送られることはありません。

6. お子様の情報

本アプリは、お子様を含め、どの利用者からも個人情報を集めません。

7. ポリシーの変更

このポリシーを変更する時は、このページを更新し、制定日・改定日を書き換えます。

8. お問い合わせ

サポートページからお問い合わせください。
